**Zenith Player** یک پخش‌کننده پیشرفته صوت و تصویر برای دسکتاپ است که با استفاده از تکنولوژی‌های وب (HTML/CSS/JS) و فریم‌ورک قدرتمند **Tauri v2** (Rust) توسعه یافته است. این پلیر علاوه بر ارائه یک تجربه بصری فوق‌العاده شیشه‌ای، ابزارهای کاربردی و قدرتمندی مانند **پشتیبانی از موزیک و ویدیو**، **زیرنویس همزمان و تعاملی (کپی کلمه به کلمه برای زبان‌آموزی)**، **ویرایشگر تعاملی اسکرین‌شات و استودیو نقاشی**، **کنترل‌های زوم و جابجایی تصویر (Pan & Zoom)** و **سیستم بوک‌مارک پیشرفته** را در اختیارتان قرار می‌دهد.

## ✨ ویژگی‌های کلیدی (Key Features)

### 🎨 رابط کاربری و طراحی (UI & UX)
*   **طراحی Glassmorphism:** افکت شیشه‌ای مات و شفاف (Frosted Glass) بر اساس استانداردهای مدرن روز (مشابه Video.js v10).
*   **نوار عنوان اختصاصی ویندوز ۱۱:** پشتیبانی کامل از دکمه‌های کنترل پنجره (Minimize/Maximize/Close) و قابلیت **پونز (Always on Top)**.
*   **تم تاریک و روشن (Dark / Light Mode):** جابجایی هوشمند و فوری تم با کلیک و انطباق هارمونیک رنگ‌ها.
*   **پس‌زمینه پویا (Dynamic Ambient Orbs):** هاله‌های نوری شناور در پس‌زمینه برای عمق‌بخشی به محیط برنامه.
*   **پیش‌نمایش فوق‌سریع بندانگشتی (Ultra-Fast Thumbnail Preview):** پیش‌نمایش آنی فریم‌ها روی نوار زمان با بهره‌گیری از شتاب سخت‌افزاری `fastSeek` و مصرف رم نزدیک به صفر.

### 🎬 پخش و کنترل مدیا (صوت و تصویر)
*   **پشتیبانی از انواع فایل‌های صوتی و تصویری:** پخش فرمت‌های ویدیویی (MP4, MKV, AVI, MOV, WEBM, TS, FLV) و فرمت‌های موزیک (MP3, FLAC, WAV, AAC, M4A, OGG).
*   **یکپارچگی با ویندوز (Windows Integration):** باز کردن مستقیم فایل‌ها با دابل‌کلیک، راست‌کلیک (Open with)، خط فرمان یا درگ روی آیکون برنامه.
*   **کنترل سرعت هوشمند:** تنظیم دقیق سرعت پخش از **0.1x** تا **10.0x**.
*   **زوم و جابجایی تصویر (Pan & Zoom):** بزرگ‌نمایی، کوچک‌نمایی و جابجایی فریم ویدیو با کلیدهای Numpad یا اسکرول ماوس.
*   **گام به فریم (Frame Stepping):** حرکت دقیق فریم به فریم روی ویدیو با کلید `F`.
*   **ادامه پخش هوشمند (Resume Playback):** ذخیره خودکار ثانیه پخش و شناسایی مشترک فایل‌ها در تمام روش‌های باز کردن.
*   **پنجره در پنجره (Picture-in-Picture):** تماشای شناور ویدیو همزمان با انجام سایر کارها.

### 📝 سیستم زیرنویس پیشرفته و زبان‌آموزی
*   **پشتیبانی از فرمت‌های SRT, VTT, ASS:** پردازش فوق‌سریع زیرنویس‌ها با Web Workers بدون افت فریم.
*   **کپسول‌های تعاملی کلمات (Interactive Word Capsules):** هاور شیشه‌ای روی تک‌تک کلمات با اسکیل ملایم، بدون به هم ریختن فاصله طبیعی کلمات.
*   **کپی کلمه به کلمه و جمله‌ای:** کپی مستقیم هر کلمه با یک کلیک (مناسب برای دیکشنری و ترجمه) یا کپی کل جمله با کلید `D` همراه با افکت فلاش سبز زمردی.
*   **زیرنویس دوگانه (Dual Subtitles):** نمایش همزمان دو زیرنویس مستقل (مثلاً فارسی و انگلیسی) در بالا و پایین تصویر.
*   **شخصی‌سازی گسترده:** تغییر فونت، رنگ، پس‌زمینه (شیشه‌ای، مشکی، آبی و...) و جهت متن (RTL/LTR).

### 📸 اسکرین‌شات و استودیو نقاشی (Drawing Tools)
*   **ثبت اسکرین‌شات هوشمند:** ثبت تصویر شفاف فریم همراه با زیرنویس‌های فعال.
*   **ابزار برش زنده (Crop):** کادربندی و برش تعاملی تصویر پیش از ذخیره‌سازی.
*   **محیط نقاشی و علامت‌گذاری:** ابزارهای مداد، پاک‌کن، پاک‌کن خطی، خط‌کشی، فلش، مستطیل، دایره و مثلث با پالت رنگی و ضخامت خطوط.
*   **تاریخچه کامل (Undo / Redo):** پشتیبانی از بازگشت و انجام مجدد با کلیدهای میانبر استاندارد.
*   **کپی مستقیم در کلیپ‌بورد:** کپی بومی تصویر در حافظه ویندوز یا دانلود فایل باکیفیت PNG.

### 🔖 بوک‌مارک، تاریخچه و پلی‌لیست
*   **سیستم بوک‌مارک پیشرفته:** نشانه‌گذاری ثانیه‌های دلخواه با نام دلخواه و نمایش خطوط راهنما روی نوار پیشرفت.
*   **پنل پلی‌لیست تعاملی:** مدیریت لیست پخش با قابلیت تغییر عرض پنل و هایلایت فایل فعال.
*   **تاریخچه لینک‌های آنلاین:** ذخیره خودکار استریم‌ها برای دسترسی آسان بعدی.

## ⌨️ کلیدهای میانبر (Keyboard Shortcuts)

### کنترل پخش (Playback Controls)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `Space` | پخش / مکث (Play / Pause) |
| `F5` | **توقف کامل پخش (Stop)** و بازگشت به ابتدای فایل |
| `Arrow Right` | پرش به ۵ ثانیه جلوتر |
| `Arrow Left` | پرش به ۵ ثانیه عقب‌تر |
| `Arrow Up` | افزایش صدا |
| `Arrow Down` | کاهش صدا |
| `C` | افزایش سرعت پخش (+0.1) |
| `X` | کاهش سرعت پخش (-0.1) |
| `Z` | سوئیچ بین سرعت فعلی و 1.0x |
| `B` | پخش فایل بعدی در پلی‌لیست |
| `N` | پخش فایل قبلی در پلی‌لیست |

### کنترل تصویر و رابط کاربری (Video & UI Controls)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `F11` | حالت تمام‌صفحه (Fullscreen) |
| `P` | باز / بستن پنل بوک‌مارک‌ها |
| `Ctrl + P` | فعال / غیرفعال کردن حالت PIP (تصویر در تصویر) |
| `Numpad 8 / 2 / 4 / 6` | تغییر مقیاس ویدیو در جهت‌های عمودی و افقی |
| `Ctrl + Numpad 8 / 2 / 4 / 6` | جابجایی (Pan) تصویر ویدیو به بالا، پایین، چپ و راست |
| `Numpad 9 / 1` | زوم به داخل (بزرگ‌نمایی) / زوم به خارج (کوچک‌نمایی) |
| `Numpad 5` | بازنشانی زوم و جابجایی تصویر به حالت اولیه |
| `Ctrl + Alt + Arrow Up / Down` | تنظیم حاشیه پایین نوار کنترل |
| `Ctrl + Alt + + / - / =` | بزرگ‌نمایی / کوچک‌نمایی نوار کنترل پایین |
| `Ctrl + Shift + + / - / =` | بزرگ‌نمایی / کوچک‌نمایی پنل تنظیمات |
| `<` و `>` (کاما و نقطه) | **بازنشانی تمام مقیاس‌های پنل‌ها به حالت پیش‌فرض** |

### کنترل و یادگیری با زیرنویس (Subtitle Controls)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `D` | **کپی کل جمله زیرنویس اول (اصلی)** + افکت نوری سبز |
| `Shift + D` | **کپی کل جمله زیرنویس دوم (بالایی)** + افکت نوری سبز |
| `Click` روی هر کلمه | **کپی فوری همان کلمه** در کلیپ‌بورد |
| `Shift + Click` | کپی کل جمله زیرنویس |
| `=` / `+` | افزایش اندازه فونت **زیرنویس اول (پایین)** |
| `-` | کاهش اندازه فونت **زیرنویس اول (پایین)** |
| `Shift + =` / `Shift + +` | افزایش اندازه فونت **زیرنویس دوم (بالا)** |
| `Shift + -` | کاهش اندازه فونت **زیرنویس دوم (بالا)** |
| `Ctrl + Arrow Keys` | جابجایی موقعیت **زیرنویس اول** روی تصویر |
| `Ctrl + Shift + Arrow Keys`| جابجایی موقعیت **زیرنویس دوم** روی تصویر |
| `[` و `]` | **بازنشانی موقعیت و اندازه هر دو زیرنویس** |

### بوک‌مارک‌ها (Bookmarks)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `K` | افزودن بوک‌مارک در زمان فعلی (همراه با کادر نام‌گذاری) |
| `L` | حذف بوک‌مارک موجود در زمان فعلی |

### اسکرین‌شات و استودیو نقاشی (Screenshot & Drawing)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `S` | ثبت اسکرین‌شات و باز شدن ویرایشگر تصویر |
| `Escape` | خروج از حالت نقاشی / خروج از برش (Crop) / بستن پنجره |
| `Enter` | تایید و اعمال نقاشی یا برش تصویر |
| `Ctrl + Z` | بازگشت (Undo) آخرین خط کشیده شده |
| `Ctrl + Y` | انجام مجدد (Redo) آخرین خط کشیده شده |

## 🚀 نحوه نصب و اجرا (Installation & Setup)

1. [Node.js](https://nodejs.org/) (نسخه 18 به بالا)
2. [Rust](https://www.rust-lang.org/)
3. ابزارهای توسعه C++ (در ویندوز: Visual Studio C++ Build Tools)

### مراحل اجرا در محیط توسعه:
```bash
# ۱. کلون کردن مخزن
git clone https://github.com/your-username/zenith-player.git
cd zenith-player

# ۲. نصب پکیج‌ها
npm install

# ۳. اجرای برنامه در حالت توسعه
npm run tauri dev

# ۴. ساخت فایل نصبی نهایی
npm run tauri build
