**Zenith Player** یک پخش‌کننده ویدیوی پیشرفته است که با استفاده از تکنولوژی‌های وب (HTML/CSS/JS) و فریم‌ورک قدرتمند **Tauri** (Rust) برای دسکتاپ توسعه یافته است. این پلیر نه تنها یک تجربه بصری خیره‌کننده را ارائه می‌دهد، بلکه ابزارهای بی‌نظیری مانند پشتیبانی از **زیرنویس همزمان (Dual Subtitles)**، **ابزار اسکرین‌شات با قابلیت نقاشی و برش**، و **سیستم بوک‌مارک پیشرفته** را در اختیار شما قرار می‌دهد.

---

## ✨ ویژگی‌های کلیدی (Features)

### 🎨 رابط کاربری و طراحی (UI / UX)
*   **طراحی Glassmorphism:** افکت‌های شیشه‌ای خیره‌کننده مشابه استاندارد Video.js v10.
*   **تم‌های تاریک و روشن (Dark / Light Mode):** تغییر تم با یک کلیک و تغییر رنگ‌های هوشمند.
*   **پس‌زمینه پویا (Ambient Orbs):** افکت‌های نوری پس‌زمینه که به زیبایی پلیر می‌افزایند.
*   **نمایشگر شناور پیش‌نمایش:** نمایش Thumbnail و زمان روی نوار پیشرفت (Progress Bar) هنگام هاور کردن موس.

### 🎬 پخش و کنترل ویدیو
*   **پشتیبانی از فایل‌های محلی و آنلاین:** پخش ویدیو از روی سیستم با Drag & Drop یا وارد کردن لینک (URL).
*   **کنترل سرعت هوشمند:** تغییر سرعت پخش تا **10x**.
*   **زوم و جابجایی تصویر (Pan & Zoom):** امکان زوم کردن روی ویدیو و جابجایی تصویر با کلیدهای Numpad یا اسکرول موس.
*   **فیلترهای رنگی:** فیلترهای Luma و Invert برای تغییر رنگ ویدیو و اسکرین‌شات‌ها.
*   **ادامه پخش (Resume Playback):** به خاطر سپردن آخرین ثانیه پخش و پیشنهاد برای ادامه آن در اجرای بعدی.
*   **پنجره در پنجره (Picture-in-Picture):** تماشای ویدیو در یک پنجره کوچک و شناور.

### 📝 سیستم زیرنویس پیشرفته
*   **پشتیبانی از زیرنویس‌های SRT, VTT, ASS:** پردازش فوق‌سریع زیرنویس‌ها با استفاده از Web Workers.
*   **زیرنویس دوگانه (Dual Subtitles):** نمایش همزمان دو زیرنویس (مثلاً فارسی و انگلیسی) در بالا و پایین تصویر.
*   **شخصی‌سازی کامل:** تغییر اندازه، رنگ، پس‌زمینه (شیشه‌ای، مشکی، آبی و...) و تغییر جهت (RTL/LTR) به صورت مجزا برای هر زیرنویس.
*   **انتخاب هوشمند:** انتخاب خودکار زیرنویسِ همنام با فایل ویدیویی.

### 📸 اسکرین‌شات و ویرایشگر تصویر (Drawing Tool)
*   **گرفتن اسکرین‌شات باکیفیت:** ثبت تصویر همراه با زیرنویس‌های رندر شده روی تصویر.
*   **برش (Crop):** ابزار برش تصویر به صورت زنده.
*   **ویرایش و نقاشی روی تصویر:** ابزارهای مداد، پاک‌کن، رسم خط، فلش، مستطیل، دایره و مثلث با قابلیت انتخاب رنگ و ضخامت.
*   **تاریخچه نقاشی:** پشتیبانی از Undo و Redo.
*   **کپی و ذخیره:** کپی مستقیم تصویر در کلیپ‌بورد (Clipboard) یا دانلود آن به عنوان فایل PNG.

### 🔖 بوک‌مارک، تاریخچه و پلی‌لیست
*   **سیستم بوک‌مارک:** ثبت زمان‌های دلخواه از ویدیو همراه با نام دلخواه و نمایش آن‌ها روی نوار پیشرفت (Progress Bar).
*   **پنل پلی‌لیست:** مدیریت ویدیوهای اضافه شده با قابلیت تغییر اندازه عرض پنل.
*   **تاریخچه ویدیوهای آنلاین:** ذخیره خودکار لینک‌های پخش شده برای دسترسی سریع در آینده.

## ⌨️ کلیدهای میانبر (Keyboard Shortcuts)

تمامی عملکردهای Zenith Player برای استفاده حرفه‌ای، با کیبورد قابل کنترل هستند.

### کنترل پخش (Playback)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `Space` | پخش / مکث (Play / Pause) |
| `Arrow Right` | پرش به ۵ ثانیه جلوتر |
| `Arrow Left` | پرش به ۵ ثانیه عقب‌تر |
| `Arrow Up` | افزایش صدا |
| `Arrow Down` | کاهش صدا |
| `F` | رفتن به فریم بعدی (Frame Step) |
| `C` | افزایش سرعت پخش (+0.1) |
| `X` | کاهش سرعت پخش (-0.1) |
| `Y` | بازنشانی سرعت پخش به 1.0x (یا بازگشت به سرعت قبلی) |
| `B` | پخش ویدیوی بعدی در پلی‌لیست |
| `N` | پخش ویدیوی قبلی در پلی‌لیست |

### کنترل تصویر و رابط کاربری (Video & UI)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `F11` | تمام صفحه (Fullscreen) |
| `P` | باز/بسته کردن پنل بوک‌مارک |
| `Ctrl + P` | فعال/غیرفعال کردن حالت PIP (Picture in Picture) |
| `Numpad 8 / 2 / 4 / 6` | تغییر مقیاس (زوم/کوچک کردن) ویدیو در جهات X و Y |
| `Ctrl + Numpad 8/2/4/6` | جابجایی (Pan) تصویر ویدیو به بالا، پایین، چپ و راست |
| `Numpad 5` | بازنشانی زوم و جابجایی تصویر به حالت اولیه |
| `Ctrl + Alt + Arrow Up/Down` | تنظیم حاشیه پایین (Bottom Margin) نوار کنترل |
| `Ctrl + Alt + + / - / =` | بزرگ‌نمایی / کوچک‌نمایی نوار کنترل پایین |
| `Ctrl + Shift + + / - / =` | بزرگ‌نمایی / کوچک‌نمایی پنل تنظیمات |
| `<` و `>` (کاما و نقطه) | **بازنشانی تمام مقیاس‌های پنل‌ها به حالت پیش‌فرض** |

### کنترل زیرنویس‌ها (Subtitles)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `=` / `+` | افزایش اندازه فونت **زیرنویس اول (پایین)** |
| `-` (منها) | کاهش اندازه فونت **زیرنویس اول (پایین)** |
| `Shift + =` / `Shift + +` | افزایش اندازه فونت **زیرنویس دوم (بالا)** |
| `Shift + -` | کاهش اندازه فونت **زیرنویس دوم (بالا)** |
| `Ctrl + Arrow Keys` | جابجایی موقعیت **زیرنویس اول** روی صفحه |
| `Ctrl + Shift + Arrow Keys`| جابجایی موقعیت **زیرنویس دوم** روی صفحه |
| `[` و `]` (براکت چپ و راست)| **بازنشانی موقعیت و اندازه هر دو زیرنویس به حالت پیش‌فرض** |

### بوک‌مارک‌ها (Bookmarks)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `K` | افزودن بوک‌مارک در زمان فعلی (همراه با باز شدن دیالوگ نام) |
| `L` | حذف بوک‌مارکی که در زمان فعلی قرار دارد |

### اسکرین‌شات و ابزار نقاشی (Screenshot & Drawing)
| کلید میانبر | عملکرد |
| :--- | :--- |
| `S` | ثبت اسکرین‌شات (باز شدن پنجره ویرایشگر) |
| `Escape` | خروج از حالت نقاشی / خروج از حالت برش (Crop) / بستن پنجره |
| `Enter` | تایید و اعمال نقاشی / اعمال برش تصویر (Crop) |
| `Ctrl + Z` | بازگشت (Undo) خط کشیده شده در نقاشی |
| `Ctrl + Y` یا `Ctrl+Shift+Z`| انجام مجدد (Redo) خط کشیده شده در نقاشی |

## 🚀 نحوه نصب و اجرا (Installation & Build)

از آنجایی که این پروژه با استفاده از **Tauri** ساخته شده است، برای بیلد کردن آن به پیش‌نیازهای زیر نیاز دارید:
1. [Node.js](https://nodejs.org/)
2. [Rust](https://www.rust-lang.org/)
3. پیش‌نیازهای سیستم‌عامل برای Tauri (C++ Build tools در ویندوز، webkit2gtk در لینوکس و...)

### مراحل اجرا در محیط توسعه:
```bash
# 1. کلون کردن مخزن
git clone https://github.com/your-username/zenith-player.git
cd zenith-player

# 2. نصب وابستگی‌های Node
npm install

# 3. اجرای برنامه در حالت توسعه (Development)
npm run tauri dev
